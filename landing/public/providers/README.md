# Provider logos

Shown next to each payment provider so people recognise the one they are connecting. The logos are the providers' trademarks, used only to name them.

- Stripe, PayPal, Airtel, Binance, Bitcoin and Ethereum: [Simple Icons](https://simpleicons.org) (CC0), coloured with each brand's colour.
- MTN: Wikimedia Commons, "MTN 2022 logo.svg".
- Flutterwave, Paystack, DPO, PayU, Yo!, Eversend and TRON: the app icon each provider publishes on its own website.

Pesapal and NOWPayments have no logo here yet and show a monogram (see `src/components/provider-logo.tsx`).
